# Research Papers Repository — Project Phoenix X

This directory contains the primary peer-reviewed literature and empirical foundations underpinning the architecture, flight dynamics, RF telemetry, and multi-spectral perception of **Project Phoenix X (SIH26177 / Qualcomm Inc.)**.
